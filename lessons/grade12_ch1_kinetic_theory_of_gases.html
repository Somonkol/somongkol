ក្រសួងអប់រំ យុវជន និងកីឡា • កម្មវិធីបំប៉នបាក់ឌុបនិទ្ទេស A

ជំពូក ១ ៖ ទែម៉ូឌីណាមិច

(THERMODYNAMICS)

📚 ក្នុងជំពូក១នេះ យើងនឹងសិក្សា ៣ មេរៀនសំខាន់ៗដូចខាងក្រោម៖

1
ទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន (Kinetic Theory of Gases)

(ខ្លឹមសារពេញលេញនៃឯកសារនេះ រួមមាន៖ សម្ពាធ ថាមពលស៊ីនេទិច ល្បឿនប្រសិទ្ធ និងលំហាត់ដោះស្រាយលម្អិត)

2
ច្បាប់ទី១នៃទែម៉ូឌីណាមិច (First Law of Thermodynamics)

បម្រែបម្រួលថាមពលក្នុង កម្មន្ត កម្ដៅ និងលំនាំទែម៉ូឌីណាមិចទាំង ៤ (អ៊ីសូបារ អ៊ីសូក័រ អ៊ីសូទែម អាដ្យាបាទិច)

3
ម៉ាស៊ីន (Heat Engines & Refrigerators)

ម៉ាស៊ីនកម្ដៅ ម៉ាស៊ីនចំហេះក្នុង ម៉ាស៊ីនត្រជាក់ ខួបកាណូ និងទិន្នផលម៉ាស៊ីន

ជំពូកទី ១ • មេរៀនទី ១
រៀបរៀង និងបង្រៀនដោយ៖ លោកគ្រូ គឹម សុមង្គល (012 962 818)
ទំព័រទី 2

📖 មេរៀនទី ១ ៖ ទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន

I. ទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន (Postulates of Kinetic Theory)

ក្នុងទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន គេសិក្សាពីចលនារបស់ម៉ូលេគុលឧស្ម័នផ្ទុកក្នុងធុងមួយបិទជិតមានមាឌ \(V\)។

ទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័នមានសម្មតិកម្មគ្រឹះដូចតទៅ៖

  • ✦
    ម៉ូលេគុលឧស្ម័នទាំងអស់មានវិមាត្រតូចណាស់បើធៀបនឹងលំហអន្តរម៉ូលេគុល ដូចនេះគេចាត់ទុកវាជាចំណុចរូបធាតុ។
  • ✦
    ម៉ូលេគុលឧស្ម័ននីមួយៗមិនមានអំពើលើគ្នាទេ លើកលែងតែពេលវាទង្គិចគ្នា។
  • ✦
    ម៉ូលេគុលឧស្ម័នមានចលនាឥតឈប់ឈរ និងគ្មានសណ្តាប់ធ្នាប់ (ចលនាប្រោន) ហើយធ្វើចលនាត្រង់ស្មើនៅចន្លោះទង្គិចពីរជាប់គ្នា។
  • ✦
    ទង្គិចរវាងម៉ូលេគុលនិងម៉ូលេគុលផ្សេងទៀត ឬរវាងម៉ូលេគុលនិងធុងដែលផ្ទុកវា ជាទង្គិចខ្ទាត (Elastic Collision) (គ្មានការបាត់បង់ថាមពលស៊ីនេទិចសរុបទេ)។
  • ✦
    តម្លៃមធ្យមនៃថាមពលស៊ីនេទិចរបស់ម៉ូលេគុលនីមួយៗ អាស្រ័យតែនឹងសីតុណ្ហភាពដាច់ខាតប៉ុណ្ណោះ។

II. សម្ពាធក្នុងទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន (Pressure Derivation)

ឧបមាមានធុងមួយរាងគូបមានប្រវែងជ្រុង \(L\) ផ្ទុកឧស្ម័នចំនួន \(N\) ម៉ូលេគុល ហើយម៉ូលេគុលនីមួយៗមានម៉ាសស្មើគ្នា \(m_0\) ផ្លាស់ទីដោយសេរីមានល្បឿនរៀងគ្នា \(\vec{v}_1, \vec{v}_2, \dots, \vec{v}_N\)។

យើងសង្កេតមើលចលនារបស់ម៉ូលេគុលមួយផ្លាស់ទីទៅទង្គិចនឹងផ្ទៃជញ្ជាំង \(X\) ដោយល្បឿន៖

\(\vec{v}_1 = \vec{v}_{1x} + \vec{v}_{1y} + \vec{v}_{1z}\)
ជំហាន ១ • បរិមាណចលនាមុន និងក្រោយទង្គិច

តាមអ័ក្ស \((Ox)\)៖

• មុនពេលទង្គិច ម៉ូលេគុលមានបរិមាណចលនា៖ \(\vec{p}_{i1x} = m_0 \vec{v}_{i1x}\)

• ក្រោយទង្គិច ម៉ូលេគុលមានបរិមាណចលនា៖ \(\vec{p}_{f1x} = m_0 \vec{v}_{f1x}\)

តាមទ្រឹស្តីស៊ីនេទិច ទង្គិចរវាងម៉ូលេគុលនិងផ្ទៃជញ្ជាំងជាទង្គិចខ្ទាត នោះ៖

\(\vec{v}_{f1x} = -\vec{v}_{i1x} \implies \vec{p}_{f1x} = -m_0 \vec{v}_{i1x}\)

ជំហាន ២ • ទ្រឹស្តីអំពុលស្យុងនៃកម្លាំងក្រៅ

\(\vec{F}'_{1X,\text{collision}} \times \Delta t_{\text{collision}} = \Delta \vec{p}_{1x} = \vec{p}_{f1x} - \vec{p}_{i1x} = -m_0 \vec{v}_{i1x} - m_0 \vec{v}_{i1x} = -2m_0 \vec{v}_{i1x}\)

នាំឱ្យកម្លាំងអន្តរកម្មពេលទង្គិច៖ \(\vec{F}'_{1X,\text{collision}} = \frac{-2m_0 \vec{v}_{i1x}}{\Delta t_{\text{collision}}}\)

ជំហាន ៣ • កម្លាំងមធ្យមក្នុងមួយខួបចលនា

ដោយម៉ូលេគុលធ្វើចលនាឥតឈប់ឈរ ដូចនេះកម្លាំងមធ្យមដែលម៉ូលេគុលមួយទៅទង្គិចនឹងផ្ទៃជញ្ជាំងត្រូវគិតក្នុង ១ ខួបចលនារបស់ម៉ូលេគុលផ្លាស់ទីពីជញ្ជាំងម្ខាងទៅម្ខាងទៀតហើយត្រឡប់មកទង្គិចម្តងទៀត ដែលត្រូវនឹងរយៈពេល៖

\(\Delta t = \frac{2L}{v_{i1x}}\)

គេបាន កម្លាំងមធ្យមដែលផ្ទៃជញ្ជាំងប្រតិកម្មនឹងទង្គិចរបស់ម៉ូលេគុលមួយ គឺ៖

\((\vec{F}'_{1X})_{av} = \frac{-2m_0 \vec{v}_{i1x}}{\Delta t} = \frac{-2m_0 \vec{v}_{i1x}}{\frac{2L}{v_{i1x}}} = -\frac{m_0 \vec{v}_{i1x} \times v_{i1x}}{L}\)

សញ្ញា (-) មានន័យថាកម្លាំងក្រៅ (កម្លាំងទប់របស់ជញ្ជាំង) មានទិសដៅផ្ទុយពីល្បឿនដើម \((\vec{v}_i)\)។

ជំពូកទី ១ • មេរៀនទី ១
រៀបរៀង និងបង្រៀនដោយ៖ លោកគ្រូ គឹម សុមង្គល (012 962 818)
ទំព័រទី 3
ជំហាន ៤ • អនុវត្តច្បាប់ទី ៣ ញូតុន

តាមច្បាប់ទី ៣ ញូតុន កម្លាំងដែលម៉ូលេគុលមានអំពើលើជញ្ជាំងមានតម្លៃស្មើគ្នា និងទិសដៅផ្ទុយគ្នា៖

\((\vec{F}_{1X})_{av} = -(\vec{F}'_{1X})_{av} = \frac{m_0 \vec{v}_{i1x} \times v_{i1x}}{L}\)

គេបាន៖ \((F_{1X})_{av} = \frac{m_0 v_{i1x} \times v_{i1x}}{L} = \frac{m_0 v_{i1x}^2}{L}\)

ជំហាន ៥ • កម្លាំងមធ្យមសរុបនៃ \(N\) ម៉ូលេគុល

កម្លាំងមធ្យមសរុបដែលម៉ូលេគុលទាំងអស់មានអំពើលើជញ្ជាំង \(X\) គឺ៖

\((F_X)_{av} = (F_{1X})_{av} + (F_{2X})_{av} + \dots + (F_{NX})_{av}\)

នាំឱ្យ៖ \((F_X)_{av} = \frac{m_0 v_{i1x}^2}{L} + \frac{m_0 v_{i2x}^2}{L} + \dots + \frac{m_0 v_{iNx}^2}{L} = \frac{m_0}{L}\left(v_{i1x}^2 + v_{i2x}^2 + \dots + v_{iNx}^2\right)\)

ម្យ៉ាងទៀត ការេល្បឿនមធ្យមតាមអ័ក្សដេក៖ \(\langle v_x^2 \rangle = \frac{v_{i1x}^2 + v_{i2x}^2 + \dots + v_{iNx}^2}{N}\)

គេបាន៖ \((F_X)_{av} = \frac{m_0}{L} N \langle v_x^2 \rangle\)

ជំហាន ៦ • ក្នុងលំហ ៣ វិមាត្រ (Isotropic Motion)

យើងអាចសរសេរ៖ \(\vec{v} = \vec{v}_x + \vec{v}_y + \vec{v}_z \implies v^2 = v_x^2 + v_y^2 + v_z^2\)

ចែកអង្គទាំងពីរនឹង \(N\) គេបាន៖ \(\frac{v^2}{N} = \frac{v_x^2 + v_y^2 + v_z^2}{N} \iff \langle v^2 \rangle = \langle v_x^2 \rangle + \langle v_y^2 \rangle + \langle v_z^2 \rangle\)

ដោយម៉ូលេគុលទាំងអស់ធ្វើចលនាស្មើគ្នាគ្រប់ទិសដៅ នោះ៖ \(\langle v_x^2 \rangle = \langle v_y^2 \rangle = \langle v_z^2 \rangle\)

នាំឱ្យ៖ \(\langle v^2 \rangle = 3\langle v_x^2 \rangle \implies \langle v_x^2 \rangle = \frac{1}{3}\langle v^2 \rangle\)

គេបាន កម្លាំងសរុបដែលទៅទង្គិចនឹងផ្ទៃជញ្ជាំង គឺ៖ \(\mathbf{F = \frac{m_0 N}{3L} \langle v^2 \rangle}\)

ជំហាន ៧ • ការទាញរកសម្ពាធ P

តាមនិយមន័យសម្ពាធ៖ \(P = \frac{F}{A}\)

ដោយ \(F = \frac{m_0 N}{3L}\langle v^2 \rangle\) គេបាន \(P = \frac{m_0 N}{3LA}\langle v^2 \rangle\)

តែមាឌគូប៖ \(V = L \times A\)

រូបមន្តសម្ពាធនៃឧស្ម័នលើផ្ទៃជញ្ជាំងនីមួយៗ
\(P = \frac{1}{3}\left(\frac{N}{V}\right)m_0 \langle v^2 \rangle = \frac{1}{3}\rho \langle v^2 \rangle = \frac{1}{3}\rho v_{rms}^2 = \frac{2}{3}\left(\frac{N}{V}\right)K_{av} \quad (\text{Pa})\)
\(P\) : សម្ពាធ គិតជា (\(\text{Pa}\) ឬ \(\text{N/m}^2\))
\(F\) : កម្លាំង គិតជា (\(\text{N}\))
\(V\) : មាឌ គិតជា (\(\text{m}^3\))
\(A\) : ផ្ទៃរងកម្លាំង គិតជា (\(\text{m}^2\))
\(N = n N_A\) : ចំនួនម៉ូលេគុលសរុបនៃឧស្ម័ន
\(n = \frac{m}{M}\) : ចំនួនម៉ូលឧស្ម័ន (\(\text{mol}\))
\(m_0 = \frac{m}{N} = \frac{M}{N_A}\) : ម៉ាសម៉ូលេគុលមួយ (\(\text{kg}\))
\(\rho = \frac{m}{V} = \frac{N m_0}{V}\) : ម៉ាសមាឌ (\(\text{kg/m}^3\))
\(v_{rms} = \sqrt{\langle v^2 \rangle}\) : ល្បឿនប្រសិទ្ធ (\(\text{m/s}\))
\(K_{av} = \frac{1}{2}m_0 \langle v^2 \rangle\) : ថាមពលស៊ីនេទិចមធ្យម (\(\text{J}\))
💡 លំហាត់គំរូទី ១ (ទំព័រទី ៣) Example 1

ម៉ូលេគុលឧស្ម័នអាសូតមួយមានម៉ាស \(m_0 = 4.65 \times 10^{-26} \text{ kg}\) ផ្លាស់ទីដោយល្បឿន \(500 \text{ m/s}\) ក្នុងទិសកែងនឹងផ្ទៃជញ្ជាំងធុង ហើយទៅបុកជញ្ជាំងធុង រួចផ្លាតត្រឡប់មកវិញដោយល្បឿនដដែល។

ក. គណនាអំពុលស្យុងដែលម៉ូលេគុលមួយនេះផ្តល់ឱ្យជញ្ជាំងធុងក្នុងការទង្គិចមួយលើក។
ខ. ប្រសិនបើក្នុងរយៈពេល \(1\text{ s}\) មានម៉ូលេគុលចំនួន \(10^{23}\) បុកជញ្ជាំងធុងដែលមានផ្ទៃ \(A = 0.02 \text{ m}^2\) ក្នុងទិសដៅកែង គណនាកម្លាំងមធ្យម និងសម្ពាធដែលបង្កើតឡើងលើជញ្ជាំងនោះ។

ជំពូកទី ១ • មេរៀនទី ១
រៀបរៀង និងបង្រៀនដោយ៖ លោកគ្រូ គឹម សុមង្គល (012 962 818)
ទំព័រទី 4
✅ ដំណោះស្រាយលំហាត់គំរូទី ១
ក. គណនាអំពុលស្យុងដែលម៉ូលេគុលមួយនេះផ្តល់ឱ្យជញ្ជាំងធុងក្នុងការទង្គិចមួយលើក៖
តាមទ្រឹស្តីអំពុលស្យុង៖ \(\vec{J} = \Delta \vec{p} = \vec{p}_f - \vec{p}_i = m_0 \vec{v}_f - m_0 \vec{v}_i\)
ក្នុងទង្គិចខ្ទាត៖ \(\vec{v}_f = -\vec{v}_i \implies \vec{J} = -2m_0 \vec{v}_i\)
សញ្ញា (-) មានន័យថាអំពុលស្យុងនៃកម្លាំងក្រៅ (កម្លាំងទប់របស់ជញ្ជាំង) មានទិសដៅផ្ទុយពីល្បឿនដើម \((\vec{v}_i)\)។
ជាតម្លៃខ្នាត៖ \(|\vec{J}| = 2m_0 v_i\)
ដោយ \(m_0 = 4.65 \times 10^{-26}\text{ kg}\) ; \(v_i = 500\text{ m/s}\)
គេបាន៖ \(|\vec{J}| = 2 \times 4.65 \times 10^{-26} \times 500 = 4.65 \times 10^{-23}\text{ kg}\cdot\text{m/s}\)
ដូចនេះ អំពុលស្យុងដែលម៉ូលេគុលមួយនេះផ្តល់ឱ្យជញ្ជាំងធុងគឺ៖ \(|\vec{J}| = 4.65 \times 10^{-23}\text{ kg}\cdot\text{m/s}\)
ខ. គណនាកម្លាំងមធ្យម និងសម្ពាធលើជញ្ជាំងធុងក្នុងរយៈពេល \(1\text{ s}\)៖
តាមច្បាប់ទី ២ ញូតុន៖ \(F = \frac{N \times |\Delta p|}{\Delta t} = \frac{N |\vec{J}|}{\Delta t}\)
ដោយ \(N = 10^{23}\) ; \(|\vec{J}| = 4.65 \times 10^{-23}\text{ kg}\cdot\text{m/s}\) ; \(\Delta t = 1\text{ s}\)
គេបាន៖ \(F = \frac{10^{23} \times 4.65 \times 10^{-23}}{1} = 4.65\text{ N}\)
ដូចនេះ កម្លាំងមធ្យមដែលម៉ូលេគុលទៅទង្គិចនឹងផ្ទៃជញ្ជាំងគឺ៖ \(F = 4.65\text{ N}\)

គណនាសម្ពាធដែលបង្កើតឡើងលើជញ្ជាំងនោះ៖

តាមរូបមន្ត៖ \(P = \frac{F}{A}\)
ដោយ \(A = 0.02\text{ m}^2\) ; \(F = 4.65\text{ N}\)
គេបាន៖ \(P = \frac{4.65}{0.02} = 232.5\text{ Pa}\)
ដូចនេះ សម្ពាធដែលបង្កើតឡើងលើជញ្ជាំងនោះគឺ៖ \(P = 232.5\text{ Pa}\)
📝 លំហាត់ប្រតិបត្តិទី ១ Practice 1

ធុងមួយបិទជិតផ្ទុកឧស្ម័ន ដែលម៉ូលេគុលឧស្ម័ននីមួយៗមានម៉ាស \(m_0 = 3.3 \times 10^{-27}\text{ kg}\) ផ្លាស់ទីដោយល្បឿន \(600\text{ m/s}\) ទៅបុកជញ្ជាំងធុងមានក្រឡាផ្ទៃ \(A = 0.1\text{ m}^2\) មានទិសបង្កើតបានមុំ \(\theta = 60^\circ\) ធៀបទៅនឹងខ្សែបន្ទាត់កែងនៃជញ្ជាំង។ សន្មតថាការទង្គិចរវាងម៉ូលេគុលនិងជញ្ជាំងជាការទង្គិចដាច់ខាត។

ក. រកអំពុលស្យុងនៃម៉ូលេគុលនីមួយៗដែលផ្តល់ឱ្យជញ្ជាំង។
ខ. បើសិនជាមានការទង្គិចចំនួន \(5 \times 10^{24}\) លើកក្នុងមួយវិនាទីលើផ្ទៃ \(A\) ចូរគណនាសម្ពាធលើជញ្ជាំងធុងនោះ។

📝 លំហាត់ប្រតិបត្តិទី ២ Practice 2

ធុងមួយបិទជិតមានមាឌ \(V = 2\text{ L}\) ផ្ទុកឧស្ម័នអាកុងចំនួន \(N = 6 \times 10^{22}\) ម៉ូលេគុល។ ម៉ូលេគុលនីមួយៗមានម៉ាស \(m_0 = 6.64 \times 10^{-26}\text{ kg}\) និងមានល្បឿនការេមធ្យម \(\langle v^2 \rangle = 16 \times 10^4\text{ m}^2/\text{s}^2\)។

III. សមីការឧស្ម័នបរិសុទ្ធ និងថាមពលស៊ីនេទិច

១. សមីការឧស្ម័នបរិសុទ្ធ (Ideal Gas Equation)

ឧស្ម័នបរិសុទ្ធ គឺជាឧស្ម័នដែលត្រូវបានបង្កើតឡើងក្នុងទ្រឹស្តីដើម្បីងាយស្រួលក្នុងការសិក្សា និងងាយពន្យល់ពីលក្ខណៈនៃឧស្ម័ន។ ឧស្ម័នមួយត្រូវបានចាត់ទុកជាឧស្ម័នបរិសុទ្ធ លុះត្រាតែវាគោរពទៅតាមលក្ខខណ្ឌគ្រឹះនៃទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន។

ជំពូកទី ១ • មេរៀនទី ១
រៀបរៀង និងបង្រៀនដោយ៖ លោកគ្រូ គឹម សុមង្គល (012 962 818)
ទំព័រទី 5

តាមពិសោធន៍បង្ហាញថាសម្ពាធនៃឧស្ម័នបរិសុទ្ធ អាស្រ័យនឹងសីតុណ្ហភាពដាច់ខាត \(T\) ចំនួនម៉ូលេគុល \(N\) ហើយច្រាសសមាមាត្រនឹងមាឌនៃឧស្ម័ន \(V\)៖

\(P = k_B \frac{NT}{V}\)
សមីការសម្គាល់ភាពនៃឧស្ម័នបរិសុទ្ធ (Ideal Gas Law)
\(PV = nRT = N k_B T\)
\(R = 8.31 \text{ J/(mol}\cdot\text{K)}\) : ថេរស្រកលនៃឧស្ម័ន (Universal Gas Constant)
\(N_A = 6.02 \times 10^{23} \text{ /mol}\) : ចំនួនអាវ៉ូកាដ្រូ (Avogadro's Number)
\(k_B = \frac{R}{N_A} = 1.38 \times 10^{-23} \text{ J/K}\) : ថេរបុលស្មាន់ (Boltzmann Constant)
\(T = t_C + 273 \text{ (K)}\) : សីតុណ្ហភាពដាច់ខាតគិតជា Kelvin
☝️ ចំណាំសំខាន់៖

នៅក្នុងជីវិតពិត គ្មានឧស្ម័នណាមួយជាឧស្ម័នបរិសុទ្ធ ១០០% នោះទេ ប៉ុន្តែឧស្ម័នពិត (Real Gas) អាចមានលក្ខណៈប្រហាក់ប្រហែលនឹងឧស្ម័នបរិសុទ្ធ នៅក្រោមលក្ខខណ្ឌសម្ពាធទាប និងសីតុណ្ហភាពខ្ពស់។ ដូចនេះ ច្បាប់ទាំងឡាយរបស់ឧស្ម័នបរិសុទ្ធអាចអនុវត្តបានចំពោះឧស្ម័នពិត។

💡 លំហាត់គំរូទី ២ (ទំព័រទី ៥) Example 2

គណនាមាឌធុងដែលផ្ទុកឧស្ម័នអុកស៊ីសែន \(9.6\text{ g}\) នៅសម្ពាធ \(10^5\text{ Pa}\) និងសីតុណ្ហភាព \(300\text{ K}\)។ គេឱ្យថេរស្រកលនៃឧស្ម័ន \(R = 8.31\text{ J/(mol}\cdot\text{K)}\) និងម៉ាសម៉ូលនៃអុកស៊ីសែនគឺ \(32\text{ g/mol}\)។

✅ ដំណោះស្រាយ៖

តាមសមីការឧស្ម័នបរិសុទ្ធ៖ \(PV = nRT \implies V = \frac{nRT}{P}\)

តែ \(n = \frac{m}{M} \implies V = \frac{mRT}{MP}\)

ដោយ \(m = 9.6\text{ g}\) ; \(M = 32\text{ g/mol}\) ; \(P = 10^5\text{ Pa}\) ; \(R = 8.31\text{ J/(mol}\cdot\text{K)}\) ; \(T = 300\text{ K}\)

គេបាន៖ \(V = \frac{9.6 \times 8.31 \times 300}{32 \times 10^5} = 747.9 \times 10^{-5}\text{ m}^3\)

ដូចនេះ មាឌធុងដែលផ្ទុកឧស្ម័នអុកស៊ីសែនគឺ៖ \(V = 747.9 \times 10^{-5}\text{ m}^3\) (ឬ \(\approx 7.48\text{ L}\))
📝 លំហាត់ប្រតិបត្តិទី ១ Practice 1

ឧស្ម័នបរិសុទ្ធមួយមានមាឌ \(V = 100\text{ cm}^3\) ស្ថិតនៅក្រោមសម្ពាធ \(P = 2 \times 10^5\text{ Pa}\) នៅសីតុណ្ហភាព \(27^\circ\text{C}\)។ គណនាចំនួនម៉ូលនៃឧស្ម័ន។ គេឱ្យថេរស្រកលនៃឧស្ម័ន \(R = 8.31\text{ J/(mol}\cdot\text{K)}\)។

📝 លំហាត់ប្រតិបត្តិទី ២ Practice 2

ឧស្ម័នបរិសុទ្ធមួយមានចំនួនម៉ូល \(n = 0.008\text{ mol}\) មានសម្ពាធ \(5 \times 10^5\text{ Pa}\) នៅសីតុណ្ហភាព \(60^\circ\text{C}\)។ គេឱ្យថេរស្រកលនៃឧស្ម័ន \(R = 8.31\text{ J/(mol}\cdot\text{K)}\) និងចំនួនអាវ៉ូកាដ្រូ \(N_A = 6.02 \times 10^{23}\text{ /mol}\)។

ក. គណនាចំនួនម៉ូលេគុលឧស្ម័ន។
ខ. គណនាមាឌនៃឧស្ម័ន។

២. ថាមពលស៊ីនេទិចនៃម៉ូលេគុលឧស្ម័ន

បើម៉ូលេគុលឧស្ម័ននីមួយៗមានម៉ាសស្មើគ្នា \(m_0\) ផ្លាស់ទីដោយល្បឿនរៀងគ្នា \(\vec{v}_1, \vec{v}_2, \dots, \vec{v}_N\) មានថាមពលស៊ីនេទិករៀងគ្នា៖

\(K_1 = \frac{1}{2}m_0 v_1^2 \quad ; \quad K_2 = \frac{1}{2}m_0 v_2^2 \quad ; \quad \dots \quad ; \quad K_N = \frac{1}{2}m_0 v_N^2\)

ថាមពលស៊ីនេទិចមធ្យមនៃម៉ូលេគុលឧស្ម័នគឺ៖

\(K_{av} = \frac{K_1 + K_2 + \dots + K_N}{N} = \frac{1}{2}m_0 \left(\frac{v_1^2 + v_2^2 + \dots + v_N^2}{N}\right) \implies \mathbf{K_{av} = \frac{1}{2}m_0 \langle v^2 \rangle}\)
ជំពូកទី ១ • មេរៀនទី ១
រៀបរៀង និងបង្រៀនដោយ៖ លោកគ្រូ គឹម សុមង្គល (012 962 818)
ទំព័រទី 6

ម្យ៉ាងទៀត សម្ពាធក្នុងទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន៖ \(P = \frac{2}{3}\left(\frac{N}{V}\right)K_{av} \implies K_{av} = \frac{3}{2}\frac{PV}{N}\)

តាមសមីការឧស្ម័នបរិសុទ្ធ \(PV = N k_B T\) គេបាន៖

តម្លៃមធ្យមនៃថាមពលស៊ីនេទិចម៉ូលេគុលមួយ (Average Kinetic Energy)
\(K_{av} = \frac{3}{2}k_B T = \frac{3}{2}\frac{PV}{N} = \frac{1}{2}m_0 \langle v^2 \rangle \quad (\text{J})\)

បើឧស្ម័នមាន \(N\) ម៉ូលេគុល ថាមពលស៊ីនេទិចសរុបនៃម៉ូលេគុលឧស្ម័នទាំងអស់ គឺជាផលគុណរវាងចំនួនម៉ូលេគុល និងតម្លៃមធ្យមនៃថាមពលស៊ីនេទិចនៃម៉ូលេគុលឧស្ម័ននីមួយៗ៖

ថាមពលស៊ីនេទិចសរុប (Total Kinetic Energy)
\(K = N K_{av} = \frac{3}{2}N k_B T = \frac{3}{2}nRT = \frac{3}{2}PV = \frac{1}{2}m\langle v^2 \rangle \quad (\text{J})\)
💡 លំហាត់គំរូទី ៣ (ទំព័រទី ៦) Example 3

ធុងមួយផ្ទុកឧស្ម័នអេល្យូម \(2.00\text{ mol}\) នៅសីតុណ្ហភាព \(27^\circ\text{C}\)។ សន្មតថាអេល្យូមជាឧស្ម័នបរិសុទ្ធ។ គេឱ្យថេរបុលស្មាន់ \(k_B = 1.38 \times 10^{-23}\text{ J/K}\) និងថេរស្រកលនៃឧស្ម័ន \(R = 8.31\text{ J/(mol}\cdot\text{K)}\)។

ក. គណនាតម្លៃមធ្យមនៃថាមពលស៊ីនេទិចរបស់ម៉ូលេគុលនីមួយៗ។
ខ. គណនាថាមពលស៊ីនេទិចសរុបរបស់ម៉ូលេគុលទាំងអស់។

✅ ដំណោះស្រាយ៖
ក. គណនាតម្លៃមធ្យមនៃថាមពលស៊ីនេទិចរបស់ម៉ូលេគុលនីមួយៗ៖
តាមរូបមន្ត៖ \(K_{av} = \frac{3}{2}k_B T\)
ដោយ \(k_B = 1.38 \times 10^{-23}\text{ J/K}\) ; \(T = 27^\circ\text{C} + 273 = 300\text{ K}\)
គេបាន៖ \(K_{av} = \frac{3}{2} \times 1.38 \times 10^{-23} \times 300 = 621 \times 10^{-23}\text{ J}\)
ដូចនេះ តម្លៃមធ្យមនៃថាមពលស៊ីនេទិចរបស់ម៉ូលេគុលនីមួយៗគឺ៖ \(K_{av} = 621 \times 10^{-23}\text{ J}\) (ឬ \(6.21 \times 10^{-21}\text{ J}\))
ខ. គណនាថាមពលស៊ីនេទិចសរុបរបស់ម៉ូលេគុលទាំងអស់៖
តាមរូបមន្ត៖ \(K = \frac{3}{2}nRT\)
ដោយ \(n = 2.00\text{ mol}\) ; \(R = 8.31\text{ J/(mol}\cdot\text{K)}\) ; \(T = 300\text{ K}\)
គេបាន៖ \(K = \frac{3}{2} \times 2 \times 8.31 \times 300 = 7479\text{ J}\)
ដូចនេះ ថាមពលស៊ីនេទិចសរុបរបស់ម៉ូលេគុលទាំងអស់គឺ៖ \(K = 7479\text{ J}\)
📝 លំហាត់ប្រតិបត្តិទី ១ Practice 1

ធុងមួយមានមាឌ \(200\text{ cm}^3\) ផ្ទុកឧស្ម័នបរិសុទ្ធចំនួន \(5 \times 10^{25}\) ម៉ូលេគុល មានសម្ពាធស្មើនឹងសម្ពាធបរិយាកាស (\(1.013 \times 10^5\text{ Pa}\))។

ក. គណនាតម្លៃមធ្យមនៃថាមពលស៊ីនេទិចរបស់ម៉ូលេគុលនីមួយៗ។
ខ. គណនាថាមពលស៊ីនេទិចសរុបរបស់ម៉ូលេគុលទាំងអស់។

📝 លំហាត់ប្រតិបត្តិទី ២ Practice 2

ក្នុងបន្ទប់បិទជិតមួយមានខ្យល់ស្ងួតដែលមានម៉ាសម៉ូល \(M = 28.9\text{ g/mol}\)។ សន្មតថាម៉ូលេគុលខ្យល់ទាំងអស់ផ្លាស់ទីដោយសេរីក្នុងបន្ទប់និងមានល្បឿនស្មើៗគ្នា \(600\text{ m/s}\)។ គេឱ្យចំនួនអាវ៉ូកាដ្រូ \(N_A = 6.02 \times 10^{23}\text{ /mol}\)។

គណនាតម្លៃមធ្យមនៃថាមពលស៊ីនេទិចរបស់ម៉ូលេគុលនីមួយៗ។

៣. ល្បឿនប្រសិទ្ធនៃម៉ូលេគុលឧស្ម័ន (\(v_{rms}\))

យើងមានតម្លៃមធ្យមនៃថាមពលស៊ីនេទិច៖ \(K_{av} = \frac{1}{2}m_0 \langle v^2 \rangle = \frac{3}{2}k_B T\)

ជំពូកទី ១ • មេរៀនទី ១
រៀបរៀង និងបង្រៀនដោយ៖ លោកគ្រូ គឹម សុមង្គល (012 962 818)
ទំព័រទី 7

នាំឱ្យ៖ \(\langle v^2 \rangle = \frac{3k_B T}{m_0}\)

បំពាក់ឫសការេលើអង្គទាំងពីរ៖ \(\sqrt{\langle v^2 \rangle} = \sqrt{\frac{3k_B T}{m_0}}\)

ដូចនេះ ល្បឿនប្រសិទ្ធនៃម៉ូលេគុលឧស្ម័នឱ្យដោយកន្សោម៖

ល្បឿនប្រសិទ្ធនៃម៉ូលេគុលឧស្ម័ន (Root-Mean-Square Speed)
\(v_{rms} = \sqrt{\frac{3k_B T}{m_0}} = \sqrt{\frac{3RT}{M}} = \sqrt{\frac{3PV}{m}} = \sqrt{\frac{3P}{\rho}} \quad (\text{m/s})\)
ការបំប្លែងទម្រង់រូបមន្តល្បឿនប្រសិទ្ធ

• ដោយ \(m_0 = \frac{M}{N_A}\) នោះ \(v_{rms} = \sqrt{\frac{3k_B T}{\frac{M}{N_A}}} = \sqrt{\frac{3 N_A k_B T}{M}}\) តែ \(k_B = \frac{R}{N_A} \implies R = N_A k_B\)

គេបាន៖ \(v_{rms} = \sqrt{\frac{3RT}{M}}\)

• តាមសមីការឧស្ម័នបរិសុទ្ធ \(PV = nRT \implies RT = \frac{PV}{n}\) នាំឱ្យ៖ \(v_{rms} = \sqrt{\frac{3PV}{nM}} = \sqrt{\frac{3PV}{m}}\)

• ម្យ៉ាងទៀត ម៉ាសមាឌ \(\rho = \frac{m}{V} \implies \frac{1}{\rho} = \frac{V}{m}\) នាំឱ្យ៖ \(\mathbf{v_{rms} = \sqrt{\frac{3P}{\rho}}}\)

☝️ ចំណាំ៖

ករណីល្បឿនម៉ូលេគុលឧស្ម័ននីមួយៗស្មើគ្នា \(v_1 = v_2 = \dots = v_N = v = v_{av}\) គេបាន \(v_{rms} = v_{av}\)។

💡 លំហាត់គំរូទី ៤ (ទំព័រទី ៧) Example 4

ចូរគណនាល្បឿនប្រសិទ្ធរបស់ម៉ូលេគុលឧស្ម័នអ៊ីដ្រូសែននៅសីតុណ្ហភាព \(100^\circ\text{C}\)។ គេឱ្យ ម៉ាសម៉ូលឧស្ម័នអ៊ីដ្រូសែន \(M = 2\text{ g/mol}\) និងថេរស្រកលនៃឧស្ម័ន \(R = 8.31\text{ J/(mol}\cdot\text{K)}\)។

✅ ដំណោះស្រាយ៖

តាមរូបមន្ត៖ \(v_{rms} = \sqrt{\frac{3RT}{M}}\)

ដោយ \(R = 8.31\text{ J/(mol}\cdot\text{K)}\) ; \(T = 100^\circ\text{C} + 273 = 373\text{ K}\) ;
\(M = 2\text{ g/mol} = 2 \times 10^{-3}\text{ kg/mol}\)

គេបាន៖ \(v_{rms} = \sqrt{\frac{3 \times 8.31 \times 373}{2 \times 10^{-3}}} = 2156.25\text{ m/s}\)

ដូចនេះ ល្បឿនប្រសិទ្ធរបស់ម៉ូលេគុលឧស្ម័នអ៊ីដ្រូសែនគឺ៖ \(v_{rms} = 2156.25\text{ m/s}\)
📝 លំហាត់ប្រតិបត្តិទី ១ Practice 1

ខ. ប្រសិនបើសីតុណ្ហភាពនៃឧស្ម័នមិនប្រែប្រួល តែដង់ស៊ីតេឧស្ម័នអ៊ីដ្រូសែនថយចុះពាក់កណ្តាល។ គណនាសម្ពាធឧស្ម័នអ៊ីដ្រូសែននៅពេលនោះ។

ទំព័រទី 8
📋 មេរៀនសង្ខេប ៖ ទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន

✦ សេចក្តីសង្ខេបទ្រឹស្តីស៊ីនេទិច៖

• ម៉ូលេគុលឧស្ម័នមានវិមាត្រតូចណាស់ \(\implies\) ចាត់ទុកជាចំណុចរូបធាតុ
• មិនមានកម្លាំងអន្តរកម្មលើគ្នាទេ លើកលែងតែពេលទង្គិចគ្នា
• ចលនាឥតឈប់ឈរ គ្មានសណ្តាប់ធ្នាប់ (ចលនាប្រោន) និងធ្វើចលនាត្រង់ស្មើចន្លោះទង្គិច
• ទង្គិចទាំងអស់ជាទង្គិចខ្ទាត (Elastic Collision)
• ថាមពលស៊ីនេទិចមធ្យមអាស្រ័យតែនឹងសីតុណ្ហភាពដាច់ខាត \(T\)

ឈ្មោះរូបមន្ត រូបមន្តគណិត ខ្នាត និងសម្គាល់
សម្ពាធទូទៅ \(P = \frac{F}{A}\) \(P \text{ (Pa)}, F \text{ (N)}, A \text{ (m}^2)\)
ទ្រឹស្តីអំពុលស្យុង \(\vec{F}' \times \Delta t = \Delta \vec{p} = \vec{p}_f - \vec{p}_i\) \(\text{N}\cdot\text{s}\) ឬ \(\text{kg}\cdot\text{m/s}\)
បរិមាណចលនា \(\vec{p} = m\vec{v}\) \(\text{kg}\cdot\text{m/s}\)
សម្ពាធឧស្ម័នក្នុងទ្រឹស្តីស៊ីនេទិច \(P = \frac{1}{3}\left(\frac{N}{V}\right)m_0 \langle v^2 \rangle = \frac{1}{3}\rho \langle v^2 \rangle\)
\(P = \frac{1}{3}\rho v_{rms}^2 = \frac{2}{3}\left(\frac{N}{V}\right)K_{av}\) 		\(m_0 = \frac{m}{N} = \frac{M}{N_A}\)
\(\rho = \frac{m}{V} = \frac{N m_0}{V}\)
\(N = n N_A\) ; \(n = \frac{m}{M}\)
សមីការឧស្ម័នបរិសុទ្ធ \(PV = nRT = N k_B T\) \(R = 8.31 \text{ J/(mol}\cdot\text{K)}\)
\(N_A = 6.02 \times 10^{23} \text{ /mol}\)
\(k_B = 1.38 \times 10^{-23} \text{ J/K}\)
\(T = t_C + 273 \text{ (K)}\)
ថាមពលស៊ីនេទិចមធ្យម \(K_{av} = \frac{3}{2}k_B T = \frac{3}{2}\frac{PV}{N} = \frac{1}{2}m_0 \langle v^2 \rangle\) គិតជា \(\text{Joule (J)}\)
ថាមពលស៊ីនេទិចសរុប \(K = N K_{av} = \frac{3}{2}N k_B T = \frac{3}{2}nRT = \frac{3}{2}PV\) គិតជា \(\text{Joule (J)}\)
ល្បឿនប្រសិទ្ធ (\(v_{rms}\)) \(v_{rms} = \sqrt{\langle v^2 \rangle} = \sqrt{\frac{3k_B T}{m_0}} = \sqrt{\frac{3RT}{M}}\)
\(v_{rms} = \sqrt{\frac{3PV}{m}} = \sqrt{\frac{3P}{\rho}}\) 		គិតជា \(\text{m/s}\)
បើ \(v_1 = v_2 = \dots = v_N \implies v_{rms} = v_{av}\)

① សមីការបម្រែបម្រួលភាព
\(\frac{P_1 V_1}{T_1} = \frac{P_2 V_2}{T_2}\)
② ច្បាប់កៃលុយសាក់ (\(V = \text{ថេរ}\))
\(\frac{P_1}{T_1} = \frac{P_2}{T_2}\)
③ ច្បាប់សាល (\(P = \text{ថេរ}\))
\(\frac{V_1}{T_1} = \frac{V_2}{T_2}\)
④ ច្បាប់ប៊យ-ម៉ារយ៉ុត (\(T = \text{ថេរ}\))
\(P_1 V_1 = P_2 V_2\)

☝️ ចំណាំ៖ ខ្នាត និងការបំប្លែងខ្នាត

① សីតុណ្ហភាព

• សីតុណ្ហភាពដាច់ខាត៖ \(T_K = t_C + 273 \quad (^\circ\text{C} \to \text{K})\)

• \(1\text{ atm} = 1.013 \times 10^5\text{ Pa} = 760\text{ mmHg} = 1\text{ psi}\)
• \(1\text{ bar} = 10^5\text{ Pa}\)

☝️ គន្លឹះពិសេស ៖ របៀបប៉ាន់ស្មានតម្លៃឫសការេ (Square Root Approximation)

បើគេមាន \(\sqrt{A}\) ដែល \(A\) ជាតម្លៃខិតទៅរកចំនួនគត់ដែលអាចបញ្ចេញពីឫសបាន៖

\(\sqrt{A} = \sqrt{B \pm C} \approx \sqrt{B} \pm \frac{C}{2\sqrt{B}}\)

ដែល \(B\) ជាចំនួនគត់មានតម្លៃខិតទៅរក \(A\) ហើយអាចបញ្ចេញពីឫសបាន។

ឧទាហរណ៍ ១ ៖ \(\sqrt{10} = \sqrt{9 + 1} \approx \sqrt{9} + \frac{1}{2\sqrt{9}} = 3 + \frac{1}{6} \approx 3.16\)
ឧទាហរណ៍ ២ ៖ \(\sqrt{35.12} = \sqrt{36 - 0.88} \approx \sqrt{36} - \frac{0.88}{2\sqrt{36}} = 6 - \frac{0.88}{12} \approx 5.92\)
