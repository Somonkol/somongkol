មុខវិជ្ជា៖ រូបវិទ្យា កម្រិតថ្នាក់៖ ទី ១២ ជំពូកទី ១៖ ទែរម៉ូឌីណាមិច កាលបរិច្ឆេទ៖ ថ្ងៃទី..... ខែ..... ឆ្នាំ២០២...
មេរៀនទី ២៖ ច្បាប់ទី១ទែរម៉ូឌីណាមិច រយៈពេលបង្រៀន៖ ២ ម៉ោងសិក្សា (៩០ នាទី)
ខ្លឹមសារមេរៀន៖ I. ប្រព័ន្ធទែរម៉ូឌីណាមិច | II. កម្មន្តធ្វើដោយឧស្ម័ន និងដ្យាក្រាម (P-V) | III. ច្បាប់ទី១ទែរម៉ូឌីណាមិច (Q = W + ΔU) | IV. លំនាំពិសេស និងបំប្លែងបិទ
I. វត្ថុបំណង (OBJECTIVES)

១. វិជ្ជាសម្បទា (Knowledge)៖

  • កំណត់និយមន័យប្រព័ន្ធទែរម៉ូឌីណាមិច ភាពនៃប្រព័ន្ធ និងបំប្លែងទែរម៉ូឌីណាមិច (បិទ និងចំហ) បានត្រឹមត្រូវ។
  • កំណត់រូបមន្តគណនាកម្មន្តធ្វើដោយឧស្ម័នក្នុងលំនាំនីមួយៗតាមដ្យាក្រាម (P-V) បានច្បាស់លាស់។
  • ពោលច្បាប់ទី១ទែរម៉ូឌីណាមិច សរសេររូបមន្ត Q = W + ΔU និងបញ្ជាក់ក្បួនសញ្ញានៃ Q, W, ΔU បានត្រឹមត្រូវឥតខុសឆ្គង។
  • បកស្រាយពីលក្ខណៈនៃលំនាំអាដ្យាបាទិក (Q = 0 ⇒ W = -ΔU) និងបំប្លែងបិទ (ΔU = 0 ⇒ Q = W) បានយ៉ាងច្បាស់។

២. បំណិនសម្បទា (Skills)៖

  • គូរ និងបកស្រាយដ្យាក្រាម (P-V) សម្រាប់លំនាំអ៊ីសូបា អ៊ីសូករ អ៊ីសូទែម និងអាដ្យាបាទិកបានត្រឹមត្រូវតាមមាត្រដ្ឋាន។
  • អនុវត្តរូបមន្ត W = PΔV, W = nRT ln(Vf / Vi), U = 3/2 nRT, ΔU = 3/2 nRΔT, និង Q = W + ΔU ក្នុងការដោះស្រាយលំហាត់គំរូ និងលំហាត់ប្រតិបត្តិបានរហ័ស និងត្រឹមត្រូវ។
  • បំណិនធ្វើការងារជាក្រុម ពិភាក្សា និងដោះស្រាយបញ្ហាលំហាត់ជាក់ស្តែងដោយសមហេតុផល។

៣. ចរិយាសម្បទា (Attitude / Values)៖

  • បណ្តុះស្មារតីស្រឡាញ់ និងចូលចិត្តសិក្សាស្រាវជ្រាវមុខវិជ្ជារូបវិទ្យា និងបាតុភូតធម្មជាតិ។
  • មានទម្លាប់ប្រុងប្រយ័ត្ន ហ្មត់ចត់ ច្បាស់លាស់ក្នុងការគណនាលេខ និងការប្រើប្រាស់ខ្នាតអន្តរជាតិ (Joule, Pascal, m3, Kelvin)។
  • មានស្មារតីសន្សំសំចៃថាមពល និងយល់ដឹងពីការបំលែងថាមពលកម្ដៅទៅជាកម្មន្តមេកានិចក្នុងជីវភាពរស់នៅ។
II. សម្ភារឧបទេស និងឯកសារយោង (TEACHING AIDS & REFERENCES)

  • ផ្ទាំងគំនូរ / ស្លាយដ្យាក្រាម (P-V) បង្ហាញលំនាំទាំង ៤

  • សៀវភៅសរសេរ ប៊ិច បន្ទាត់ ក្រដាសព្រាង

ជំហានទី ១៖ រដ្ឋបាលថ្នាក់ (Class Administration) [៣ - ៥ នាទី]
- ពិនិត្យអនាម័យ បរិស្ថានក្នុងថ្នាក់ សណ្តាប់ធ្នាប់ និងឯកសណ្ឋានសិស្ស។
- ពិនិត្យវត្តមានសិស្ស និងកត់ត្រាក្នុងបញ្ជីស្រង់អវត្តមាន។
- ពង្រឹងស្មារតី និងត្រៀមរៀបចំចិត្តសិស្សឱ្យចូលរៀន។ 		- អនាម័យ និងសណ្តាប់ធ្នាប់ទូទៅក្នុងថ្នាក់រៀន
- វត្តមានសិស្សប្រចាំថ្ងៃ៖
  + ចំនួនសិស្សសរុប៖ ........ នាក់ (ស្រី ........ នាក់)
  + វត្តមាន៖ ........ នាក់ (ស្រី ........ នាក់)
  + អវត្តមាន៖ ........ នាក់ (មានច្បាប់៖ ...., ឥតច្បាប់៖ ....) 		- ប្រធានថ្នាក់ឡើងរាយការណ៍ពីអនាម័យ និងចំនួនអវត្តមានសិស្ស។
- សិស្សទាំងអស់អង្គុយតាមកន្លែងប្រកបដោយរបៀបរៀបរយ និងលើកសៀវភៅសម្ភារសិក្សាដាក់លើតុ។
ជំហានទី ២៖ រំលឹកមេរៀនចាស់ និងភ្ជាប់មេរៀនថ្មី (Review & Bridge) [៥ - ៧ នាទី]
- គ្រូសួរសំណួររំលឹកមេរៀនទី១ (ទ្រឹស្តីស៊ីនេទិចនៃឧស្ម័ន)៖
១. ចូរសរសេរសមីការភាពនៃឧស្ម័នបរិសុទ្ធ?
២. តើថាមពលស៊ីនេទិចមធ្យមនៃម៉ូលេគុលឧស្ម័នគណនាតាមរូបមន្តណា?
- គ្រូកែសម្រួលចម្លើយ និងវាយតម្លៃ។
- ភ្ជាប់មេរៀនថ្មី៖ "ប្រសិនបើយើងដុតកម្ដៅឧស្ម័នក្នុងស៊ីឡាំងបិទជិតដោយពីស្តុងចល័ត តើកម្ដៅដែលផ្តល់ឱ្យនោះបម្លែងទៅជាអ្វីខ្លះ? តើពីស្តុងកម្រើកដោយសារអ្វី?" ⇒ គ្រូនាំសិស្សចូលមេរៀនទី២។ 		១. រំលឹកមេរៀនចាស់៖
- សមីការភាពឧស្ម័នបរិសុទ្ធ៖
  PV = nRT ឬ PV = N kB T
- ថាមពលស៊ីនេទិចមធ្យមនៃម៉ូលេគុល៖
  Kavg = 3/2 kB T
២. ទំនាក់ទំនងមេរៀនថ្មី៖
កម្ដៅដែលស្រូបដោយឧស្ម័ន ត្រូវបានបំលែងទៅជាកើនថាមពលក្នុងនៃម៉ូលេគុល និងរុញពីស្តុងឱ្យរំកិល (ធ្វើកម្មន្តមេកានិច)។ នេះជាខ្លឹមសារនៃ ច្បាប់ទី១ទែរម៉ូឌីណាមិច។ 		- សិស្សស្តាប់សំណួរ គិតពិចារណា និងលើកដៃឡើងឆ្លើយ៖
+ PV = nRT
+ Kavg = 3/2 kB T
- សិស្សស្តាប់ការភ្ជាប់មេរៀន ឆ្លើយតបនឹងបាតុភូតជាក់ស្តែង និងកត់ចំណងជើងមេរៀនថ្មីចូលក្នុងសៀវភៅ។
ជំហានទី ៣៖ មេរៀនថ្មី (New Lesson Presentation) [៥០ - ៦០ នាទី]
១. ប្រព័ន្ធទែរម៉ូឌីណាមិច៖
- គ្រូសួរ៖ "តើអ្វីទៅជាប្រព័ន្ធទែរម៉ូឌីណាមិច និងមជ្ឈដ្ឋានក្រៅ?"
- គ្រូពន្យល់ពីភាពនៃប្រព័ន្ធ (សម្ពាធ P, មាឌ V, សីតុណ្ហភាព T) និងបំប្លែងបិទ/ចំហ។

២. កម្មន្តធ្វើដោយឧស្ម័ន និងដ្យាក្រាម (P-V)៖
- គ្រូបង្ហាញរូបភាពពីស្តុងរំកិលបានចម្ងាយ Δx ដោយកម្លាំង F = P·A។
- គ្រូនាំសិស្សទាញរក W = P(Vf - Vi) = PΔV។
- គ្រូពន្យល់ករណីលំនាំទាំង៤៖
 • អ៊ីសូបា (P ថេរ): W = PΔV
 • អ៊ីសូករ (V ថេរ): ΔV = 0 ⇒ W = 0
 • P ប្រែប្រួលស្មើ: W = PavΔV
 • អ៊ីសូទែម (T ថេរ): W = nRT ln(Vf/Vi)

៣. ច្បាប់ទី១ទែរម៉ូឌីណាមិច៖
- គ្រូពន្យល់និយមន័យថាមពលក្នុង U និងបម្រែបម្រួល ΔU៖
  U = 3/2 nRT, ΔU = 3/2 nRΔT
- គ្រូពោលច្បាប់ទី១ និងសរសេររូបមន្ត Q = W + ΔU។
- គ្រូសង្កត់ធ្ងន់លើ ក្បួនសញ្ញា ដែលសិស្សតែងច្រឡំ៖
 • Q > 0: ស្រូបកម្ដៅ, Q < 0: បញ្ចេញកម្ដៅ
 • W > 0: ធ្វើកម្មន្ត, W < 0: ទទួលកម្មន្ត
 • ΔU > 0: ថាមពលក្នុងកើន, ΔU < 0: ថយចុះ

៤. លំនាំពិសេស និងគោលការណ៍សមមូល៖
- គ្រូសួរ៖ "ក្នុងលំនាំអាដ្យាបាទិក តើតម្លៃ Q ស្មើប៉ុន្មាន?" ⇒ W = -ΔU
- ក្នុងបំប្លែងបិទ៖ ΔU = 0 ⇒ Q = W
- គ្រូណែនាំថា (Q - W) = ΔU អាស្រ័យតែលើភាពដើម និងភាពស្រេច មិនអាស្រ័យនឹងគន្លងឡើយ។ 		មេរៀនទី ២៖ ច្បាប់ទី១ទែរម៉ូឌីណាមិច

I. ប្រព័ន្ធទែរម៉ូឌីណាមិច៖
១. ប្រព័ន្ធ៖ វត្ថុ ឬសំណុំវត្ថុដែលលើកយកមកសិក្សាធៀបនឹងមជ្ឈដ្ឋានក្រៅ។
២. ភាពនៃប្រព័ន្ធ៖ កំណត់ដោយប៉ារ៉ាម៉ែត្រ (P, V, T)។
៣. បំប្លែងបិទ (ភាពដើម = ភាពស្រេច) និងបំប្លែងចំហ (ភាពដើម ≠ ភាពស្រេច)។

II. កម្មន្តធ្វើដោយឧស្ម័ន និងដ្យាក្រាម (P-V)៖
- និយមន័យកម្មន្ត៖ W = F·Δx = P·A·Δx = PΔV
១. ករណីសម្ពាធថេរ (លំនាំអ៊ីសូបា)៖
  W = P(Vf - Vi) = PΔV (គិតជា J)
២. ករណីមាឌថេរ (លំនាំអ៊ីសូករ)៖
  V = ថេរ (ΔV = 0) ⇒ W = 0
៣. ករណីសម្ពាធប្រែប្រួលស្មើ៖
  W = PavΔV = [(Pi + Pf)/2]·(Vf - Vi)
៤. ករណីសីតុណ្ហភាពថេរ (លំនាំអ៊ីសូទែម)៖
  W = nRT ln(Vf/Vi) = nRT ln(Pi/Pf)

III. ច្បាប់ទី១ទែរម៉ូឌីណាមិច៖
១. ថាមពលក្នុងឧស្ម័នបរិសុទ្ធម៉ូណូអាតូម៖
  U = 3/2 nRT = 3/2 PV
  ΔU = Uf - Ui = 3/2 nRΔT
២. ពោលច្បាប់ទី១៖ «ក្នុងលំនាំទែរម៉ូឌីណាមិច កម្ដៅស្រូបដោយប្រព័ន្ធ ស្មើនឹងផលបូករវាងកម្មន្តធ្វើដោយប្រព័ន្ធ និងបម្រែបម្រួលថាមពលក្នុងនៃប្រព័ន្ធ»។
  Q = W + ΔU (គិតជា J)
- ក្បួនសញ្ញា៖
 • Q > 0 (ស្រូប), Q < 0 (បញ្ចេញ)
 • W > 0 (ឧស្ម័នធ្វើកម្មន្ត), W < 0 (ឧស្ម័នរងកម្មន្ត)
 • ΔU > 0 (ថាមពលកើន), ΔU < 0 (ថាមពលថយ)

IV. លំនាំពិសេស និងគោលការណ៍សមមូល៖
- លំនាំអាដ្យាបាទិក (Q = 0): W = -ΔU
- បំប្លែងបិទ (ΔU = 0): Q = W
- គោលការណ៍ភាពដើម និងភាពស្រេច៖
  ΔU = Q - W អាស្រ័យតែនឹងភាពដើម និងស្រេច។ 		- សិស្សស្តាប់ការបកស្រាយ ចូលរួមឆ្លើយសំណួរ និងកត់ត្រានិយមន័យ។
- សង្កេតដ្យាក្រាម (P-V) និងចូលរួមទាញរូបមន្ត W = PΔV។
- កត់ចំណាំរូបមន្តកម្មន្តទាំង ៤ ករណីចូលក្នុងសៀវភៅ។

- សិស្សស្ម័គ្រចិត្តម្នាក់ឡើងពោលច្បាប់ទី១ទែរម៉ូឌីណាមិច។
- សិស្សកត់ត្រារូបមន្ត Q = W + ΔU និងទន្ទេញចាំក្បួនសញ្ញាយ៉ាងច្បាស់លាស់។

- ពិភាក្សាគ្នាពីលក្ខណៈនៃលំនាំអាដ្យាបាទិក និងបំប្លែងបិទ។
ជំហានទី ៤៖ ពង្រឹងពុទ្ធិ / ចំណេះដឹង (Consolidation) [១០ - ១៥ នាទី]
- គ្រូដាក់លំហាត់គំរូអនុវត្តន៍ផ្ទាល់លើក្ដារខៀន៖
លំហាត់៖ ប្រព័ន្ធទែរម៉ូឌីណាមិចមួយស្រូបកម្ដៅ Q = 500 cal និងធ្វើកម្មន្ត W = 400 J។ ចូរគណនាបម្រែបម្រួលថាមពលក្នុង ΔU នៃប្រព័ន្ធ? (គេឱ្យ 1 cal = 4.19 J)។
- គ្រូហៅសិស្សម្នាក់ឡើងដោះស្រាយលើក្ដារខៀន និងឱ្យសិស្សដទៃធ្វើលើក្រដាសព្រាង។
- គ្រូត្រួតពិនិត្យ ដាក់ពិន្ទុលើកទឹកចិត្ត និងកែតម្រូវរួម។ 		ដំណោះស្រាយលំហាត់ពង្រឹងពុទ្ធិ៖
- គណនាបម្រែបម្រួលថាមពលក្នុង ΔU៖
តាមច្បាប់ទី១ទែរម៉ូឌីណាមិច៖
  Q = W + ΔU ⇒ ΔU = Q - W
ដោយប្រព័ន្ធស្រូបកម្ដៅ Q > 0៖
  Q = 500 × 4.19 J = 2095 J
ប្រព័ន្ធធ្វើកម្មន្ត W > 0៖
  W = 400 J
គេបាន៖
  ΔU = 2095 - 400 = 1695 J
ដូចនេះ ថាមពលក្នុងនៃប្រព័ន្ធកើនឡើង 1695 J។ 		- សិស្សទាំងអស់យកក្រដាសព្រាងគណនាដោយផ្ចិតផ្ចង់។
- សិស្សតំណាងឡើងធ្វើលើក្ដារខៀន បង្ហាញជំហានគណនា និងប្តូរខ្នាតត្រឹមត្រូវ។
- សិស្សក្នុងថ្នាក់ផ្ទៀងផ្ទាត់ចម្លើយ និងកែកំហុសឆ្គង (បើមាន)។
ជំហានទី ៥៖ កិច្ចការផ្ទះ និងបណ្តាំផ្ញើ (Homework & Directives) [៣ - ៥ នាទី]
- គ្រូដាក់កិច្ចការផ្ទះចំនួន ២ សំណួរ៖
១. ឧស្ម័នមួយទទួលរងបំប្លែងអាដ្យាបាទិកដោយរងកម្មន្ត 640 J ពីក្រៅ។ គណនា ΔU នៃឧស្ម័ន?
២. ធ្វើលំហាត់ប្រតិបត្តិទី១ និងទី២ ទំព័រទី ២១ នៃឯកសារមេរៀន។
- បណ្តាំផ្ញើ៖ ដាស់តឿនសិស្សឱ្យមើលមេរៀនឡើងវិញ ហាត់គូរដ្យាក្រាម (P-V) និងអានត្រៀម មេរៀនទី ៣៖ ម៉ាស៊ីន សម្រាប់ម៉ោងក្រោយ។ 		១. កិច្ចការផ្ទះ (Homework)៖
- លំហាត់ទី១៖ គណនា ΔU ក្នុងលំនាំអាដ្យាបាទិក (W = -640 J ⇒ ΔU = 640 J)។
- លំហាត់ទី២៖ ប្រតិបត្តិទី១ និងទី២ ទំព័រ ២១។

២. បណ្តាំផ្ញើ (Advice)៖
- រំលឹកមេរៀន និងរូបមន្តច្បាប់ទី១ទែរម៉ូឌីណាមិច
- អានមុននូវមេរៀនទី៣៖ ម៉ាស៊ីន (ទំព័រ ២៧) 		- សិស្សកត់កិច្ចការផ្ទះចូលក្នុងសៀវភៅដោយយកចិត្តទុកដាក់។
- ទទួលយកបណ្តាំផ្ញើរបស់គ្រូ និងត្រៀមរៀបចំសៀវភៅសម្រាប់ម៉ោងបន្ទាប់។
