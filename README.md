# Kim Somangkol Physics (Ap-phy)

គេហទំព័ររូបវិទ្យា និងបន្ទប់ពិសោធន៍និម្មិត (Virtual Physics Lab & Learning Platform) បង្រៀនដោយ លោកគ្រូ **គឹម សុមង្គល**។

## មុខងារពិសោធន៍និម្មិត (Interactive Virtual Lab)
- ⚡ **បាតុភូតអាំងឌុចស្យុងអេឡិចត្រូម៉ាញេទិច (Electromagnetic Induction):** ពិសោធន៍ច្បាប់ហ្វារ៉ាដេ និងច្បាប់ឡិន (\(e = -N\frac{\Delta\Phi}{\Delta t}\)) ជាមួយមេដែករបារ រំកិលចូល/ចេញក្នុងរបុំសូឡេណូអ៊ីត ទ្រនិចហ្គាល់វ៉ាណូម៉ែត្រ និងអំពូលភ្លើង។
- 🧲 **បាតុភូតអូតូអាំងឌុចស្យុងអេឡិចត្រូម៉ាញេទិច (Electromagnetic Self-Induction):** ពិសោធន៍សៀគ្វី RL ជាមួយបូប៊ីនមានស្នូលដែក បង្ហាញការបង្កើតចរន្តពន្យឺត (\(e = -L\frac{\Delta i}{\Delta t}\)) ការផ្ដាច់ចរន្តបង្កជាភ្លើងឆាប (Spark) ថាមពលសន្សុក (\(W_L = \frac{1}{2} L i^2\)) និងម៉ូនីទ័រអូស៊ីឡូស្កុបជាក់ស្ដែង។
- 🧪 **ច្បាប់ឧស្ម័ន (Gas Laws):** ច្បាប់ប៊យ (\(P_1 V_1 = P_2 V_2\)), ច្បាប់សាល (\(\frac{V_1}{T_1} = \frac{V_2}{T_2}\)), ច្បាប់កេលុយសាក់ (\(\frac{P_1}{T_1} = \frac{P_2}{T_2}\))។
- ⏱️ **មេកានិច និងអុបទិច:** លោលទោល, ព្រីសបំបែកពន្លឺ, និងចលនាបោះក្នុងដែនទំនាញដី។
- 🧮 **ឧបករណ៍គណនារូបមន្តរូបវិទ្យារហ័ស (MathType Solver):** គណនាសមីការចលនា, កម្លាំងញូតុន, ថាមពលស៊ីនេទិច, ច្បាប់អូម, ច្បាប់ហ្វារ៉ាដេ និងអូតូអាំងឌុចស្យុង។
- 📋 **តារាងបញ្ជីឈ្មោះសិស្សជាក់ស្តែង & Google Sheets (Real Student Directory & Integration):**
  - **តាមដានសិស្សជាក់ស្តែង (Actual Count):** បង្ហាញព័ត៌មានតាមចំនួនសិស្សជាក់ស្តែងដែលបានចុះឈ្មោះ (ល.រ, ឈ្មោះសិស្ស, ថ្នាក់ទី, ថ្ងៃនិងម៉ោងសិក្សា, លេខទូរស័ព្ទ/Telegram, កាលបរិច្ឆេទ)។
  - **ផ្ទាំងជូនដំណឹងពេលសិស្សចុះឈ្មោះ (Enrollment Alert Modal & Chime):** បង្ហាញផ្ទាំង Popup ភ្លាមៗដល់អ្នកប្រើប្រាស់/លោកគ្រូ ជាមួយព័ត៌មានលម្អិត និងសំឡេងជោគជ័យ។
  - **ជម្រើសថ្ងៃ និងម៉ោងសិក្សាមានកំណត់ច្បាស់លាស់ (Study Schedule Slots):**
    - **ចន្ទ - សុក្រ:** ម៉ោង 1-2, ម៉ោង 3-4, ម៉ោង 4-5, ម៉ោង 5-6, ម៉ោង 6-7, ម៉ោង 7-8
    - **សៅរ៍ - អាទិត្យ:** ម៉ោង 1-3, ម៉ោង 3-5
  - **ការភ្ជាប់ជាមួយ Google Sheets ក្នុង My Drive:**
    - ប៊ូតុងបើក Google Sheets ក្នុង My Drive ផ្ទាល់ និងអាចកំណត់ Link ផ្ទាល់ខ្លួន
    - មុខងារ "📋 ចម្លងសម្រាប់ Sheets" (Tab-Separated Values) សម្រាប់ Ctrl+V បិទភ្ជាប់ចូល Sheets បានស្អាតតាមជួរឈរភ្លាមៗ
    - មុខងារទាញយកជា CSV (UTF-8 BOM) និងការភ្ជាប់ Webhook Google Apps Script ស្វ័យប្រវត្តិ
    - ប៊ូតុងបន្ថែមសិស្សផ្ទាល់ (➕ Quick Add) និងគ្រប់គ្រងទិន្នន័យជាក់ស្តែង
