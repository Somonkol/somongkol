## មុខងារពិសោធន៍និម្មិត (Interactive Virtual Lab)
- ⚡ **បាតុភូតអាំងឌុចស្យុងអេឡិចត្រូម៉ាញេទិច (Electromagnetic Induction):** ពិសោធន៍ច្បាប់ហ្វារ៉ាដេ និងច្បាប់ឡិន (\(e = -N\frac{\Delta\Phi}{\Delta t}\)) ជាមួយមេដែករបារ រំកិលចូល/ចេញក្នុងរបុំសូឡេណូអ៊ីត ទ្រនិចហ្គាល់វ៉ាណូម៉ែត្រ និងអំពូលភ្លើង។
- 🧲 **បាតុភូតអូតូអាំងឌុចស្យុងអេឡិចត្រូម៉ាញេទិច (Electromagnetic Self-Induction):** ពិសោធន៍សៀគ្វី RL ជាមួយបូប៊ីនមានស្នូលដែក បង្ហាញការបង្កើតចរន្តពន្យឺត (\(e = -L\frac{\Delta i}{\Delta t}\)) ការផ្ដាច់ចរន្តបង្កជាភ្លើងឆាប (Spark) ថាមពលសន្សុក (\(W_L = \frac{1}{2} L i^2\)) និងម៉ូនីទ័រអូស៊ីឡូស្កុបជាក់ស្ដែង។
- 🧪 **ច្បាប់ឧស្ម័ន (Gas Laws):** ច្បាប់ប៊យ (\(P_1 V_1 = P_2 V_2\)), ច្បាប់សាល (\(\frac{V_1}{T_1} = \frac{V_2}{T_2}\)), ច្បាប់កេលុយសាក់ (\(\frac{P_1}{T_1} = \frac{P_2}{T_2}\))។
- ⏱️ **មេកានិច និងអុបទិច:** លោលទោល, ព្រីសបំបែកពន្លឺ, និងចលនាបោះក្នុងដែនទំនាញដី។
- 🧮 **ឧបករណ៍គណនារូបមន្តរូបវិទ្យារហ័ស (MathType Solver):** គណនាសមីការចលនា, កម្លាំងញូតុន, ថាមពលស៊ីនេទិច, ច្បាប់អូម, ច្បាប់ហ្វារ៉ាដេ និងអូតូអាំងឌុចស្យុង។
- 📋 **តារាងបញ្ជីឈ្មោះសិស្សចុះឈ្មោះចូលរៀន (Student Enrollment Directory):** បង្ហាញបញ្ជីឈ្មោះសិស្សតាមតារាង (ល.រ, ឈ្មោះ, ថ្នាក់ទី, ម៉ោងសិក្សា, ស្ថានភាព) ជាមួយមុខងារស្វែងរក តម្រងកម្រិតថ្នាក់ និងតំណភ្ជាប់ផ្ទាល់ទៅកាន់ Google Sheets ក្នុង My Drive។
